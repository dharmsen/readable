## Overview
I want to write a skill that translates Claude Code prose output (e.g., from plans, specifications, explanations) to simple, intuitive text.

## Text style
### General style
- Simple and factual writing style
- Intuition and example driven
- Textbook explanations
- Utilize ASD-STE100 Simplified Technical English (STE)
- Keep sentences short
- Limit paragraph length
- Use clear headings
- Leverage bulleted and numbered lists

### Prioritize visual understanding
- Prefer figures when feasible and helpful
- Apply preference only when the available tools, data, and rendering support make a useful, accurate figure practical.
- Build intuition with a concrete example and a visual (like in textbooks).
- Favor a few informative figures over decoration or a fixed figure quota.
